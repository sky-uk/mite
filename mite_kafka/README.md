# mite_kafka

mite's Kafka integration, built on
[aiokafka](https://aiokafka.readthedocs.io/). Installs a producer and a
consumer onto the journey context and reports metrics for both.

Install: `pip install mite[kafka]`

Full documentation:
https://github.com/sky-uk/mite/blob/master/docs/plugins/kafka.md
