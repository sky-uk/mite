# mite_browser

HTML-scraping integration for mite, built on `mite_http` and BeautifulSoup:
a page/form/link API for scripting navigation and form submission over plain
HTTP, without a real browser engine or JavaScript execution.

Install: `pip install mite[browser]`

Full documentation:
https://github.com/sky-uk/mite/blob/master/docs/plugins/browser.md
