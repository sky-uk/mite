# mite_amqp

mite's AMQP integration, built on
[aio_pika](https://docs.aio-pika.com/). Installs a connection helper onto
the journey context; everything past that point is plain `aio_pika`.

Install: `pip install mite[amqp]`

Full documentation:
https://github.com/sky-uk/mite/blob/master/docs/plugins/amqp.md
